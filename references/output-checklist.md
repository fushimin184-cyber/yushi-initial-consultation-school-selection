# 交付前检查

## 数据
- 项目仍开设
- 项目名称无旧称/错别字
- 官方链接准确
- QS 排名年份统一
- 雅思总分与单项清楚
- 学术要求没有把“建议”写成“硬门槛”

## 结构
- 主标题与日期正确
- 一、学生背景综合评估
- 二、目标地区选校方案
- 四、时间规划建议
- 五、下一步行动清单
- 服务方案图
- YUSHI 两个官网链接

## 版式
- A4 纵向
- 表头浅灰
- 超链接蓝色
- 推荐项目高亮不过度
- 无删除线（除非用户要求）
- 无表格越界
- 无孤行/标题单独落在页尾
- 无乱码或黑方块


## 交付格式
- 默认最终交付为已验证 `.docx` Word 文档与同内容 `.zip` 备用下载
- PDF/PNG 仅可用于内部版式核验，不作为默认交付
- 除非用户明确额外要求，不生成 PDF

- 下载文件名为短英文/数字/下划线/连字符，正文标题仍为中文
- DOCX 非空、可读，OOXML 必需部件齐全，CRC 与 XML 检查通过
- 保存后使用 python-docx 重新打开，与保存前正文 XML 比较一致
- ZIP 可解压，内含且仅含同一 DOCX，字节完全一致
- 链接对应实际可读的绝对路径；检查大小与 SHA-256
- PDF 明确要求时转换，验证非空、有页面、可解析，完成逐页版式检查
- PDF 失败明确说明，仍交付已验证 DOCX/ZIP；不链接旧 PDF
- 参考 `delivery-workflow.md` 处理预览/下载失败，不宣称本地验证证明客户端下载成功
